# Toko Ce Alin Design System

## Overview

Toko Ce Alin merupakan sistem informasi pengelolaan stok dan operasional toko yang dirancang untuk membantu owner dan
karyawan dalam mengelola barang, transaksi penjualan, laporan, serta aktivitas operasional toko secara digital.

Design language sistem berfokus pada:

* Professional
* Clean
* Modern
* Easy To Use
* Business Oriented

# Design Direction

Dashboard harus terlihat sebagai aplikasi operasional toko modern.

Bukan marketplace.

Bukan aplikasi media sosial.

Bukan dashboard startup kripto.

Fokus utama sistem adalah:

* Pengelolaan Stok Barang
* Lokasi Rak Barang
* Kasir
* Persetujuan Diskon
* Riwayat Transaksi
* Laporan Penjualan
* Pengaturan Operasional Toko
